Fundamentos

¿Qué es Git y qué es GitHub?

Dos cosas diferentes que casi siempre van juntas. Entender la diferencia es el primer paso.

🌳

Git — el sistema

Git es un sistema de control de versiones distribuido que se instala en tu ordenador. Guarda "fotografías" (commits) de tu proyecto para que puedas volver atrás, comparar cambios y trabajar en paralelo sin miedo a romper nada. Funciona sin conexión a internet.

☁️

GitHub — la plataforma

GitHub es una plataforma en la nube (propiedad de Microsoft) que aloja repositorios Git. Añade colaboración, issues, Pull Requests, Actions (CI/CD), GitHub Pages y una enorme comunidad. Existen alternativas: GitLab, Bitbucket, Codeberg…

💡 Analogía rápida: Git es como el cuaderno de bocetos que guardas en tu mochila. GitHub es la galería online donde expones esos bocetos y otros artistas te dejan comentarios.

Metodología

Flujo de trabajo con Pull Requests

El ciclo profesional que usan los equipos de todo el mundo.

Fork o clonar el repositorio

Creas tu propia copia del proyecto en tu cuenta o lo descargas a tu equipo.

git clone https://github.com/usuario/proyecto.git

Crear una rama descriptiva

Nunca trabajes directamente sobre main. Usa nombres como feat/login o fix/header.

git checkout -b feat/mi-nueva-funcion

Hacer cambios y commitear

Añade archivos al staging area y crea commits pequeños con mensajes claros.

git add . && git commit -m "feat: añade formulario de login"

Subir la rama a GitHub

Envías tu rama al repositorio remoto para que otros puedan verla.

git push -u origin feat/mi-nueva-funcion

Abrir un Pull Request

En GitHub pulsas "Compare & pull request", describes tus cambios y pides revisión.

Revisión y merge

El equipo comenta, sugiere cambios y, cuando todo está bien, se fusiona con main.

Publicar

Publica tu web gratis con GitHub Pages

Convierte cualquier repositorio en un sitio web público en menos de 2 minutos.

Paso 01

Crea el repositorio

Sube tu proyecto. El archivo principal debe llamarse index.html y estar en la raíz.

Paso 02

Activa Pages

Ve a Settings → Pages. En "Source" selecciona la rama main y la carpeta /root. Guarda.

Paso 03

¡Listo!

En 1-2 minutos tu web estará en https://tuusuario.github.io/turepositorio/

⚡ Truco: si nombras el repositorio tuusuario.github.io, tu web quedará directamente en la raíz: https://tuusuario.github.io. Ideal para tu portafolio.
